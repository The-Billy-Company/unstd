Fix `toml.dumps`/`toml.dump` writing text stdlib `tomllib` cannot read. ESC in plain strings and keys is now spelled `\u001b` instead of the TOML 1.1-only `\e`. UTC offsets that are not whole minutes, and `time` values carrying an offset, now raise `ValueError` before anything is written, where tomlkit used to emit syntax no TOML version accepts. Items already inside a parsed or tomlkit-built document keep their spelling. `toml.dumps` is no longer the same object as `tomlkit.dumps`.
