Fix two defects in the `unstd.pack.binpack` struct array path (the portable helpers and the no-NumPy fallback). Dtype sizes were parsed with `int()`, so spellings such as `"i4 "`, `"i0_4"`, `"i+4"` or non-ASCII digits were accepted as `int32`; only exact typestrs and documented aliases are accepted now. Non-memoryview buffers were also sized with `len()`, so an 8-byte `array("i")` was rejected as "buffer size 2" and contiguous ndarrays failed or were misreported. Every contiguous buffer exporter is now measured in bytes.
