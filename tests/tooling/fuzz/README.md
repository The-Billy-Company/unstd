# Parser and token fuzzing

This is executable assurance tooling: eleven real parser/token targets, reviewed
synthetic corpora, authenticated deterministic replay, reproducible byte mutation,
and genuine Atheris/libFuzzer campaigns. The ordinary pytest lane replays fixed
inputs; sustained mutation runs through this module and has separate budgets.
Target assertions and failure handling are tested under
[`assurance/gates/fuzz`](../../suites/assurance/gates/fuzz/).

## Prepare and inspect

Use `--no-sync` when running to retain the backend combination under test.

```console
uv sync --locked --all-extras --group dev
uv run --no-sync python -m tests.tooling.fuzz list
uv run --no-sync python -m tests.tooling.fuzz list --json
uv run --no-sync python -m tests.tooling.fuzz list --json --all-backends
uv run --no-sync python -m tests.tooling.fuzz check
```

`registry.toml` owns target identities, supported backends, installed imports,
envelope versions and input budgets. `check` authenticates every `seeds.json`
manifest and its exact files: hashes, sizes, uniqueness, reviewed labels/origins,
valid/invalid/boundary controls, minimum seed counts and discovery parity.
Unregistered targets, orphan files, altered seeds, symlinks and empty or
underfed corpora fail admission. Each target has at least twelve reviewed seeds.
The JSON listing with `--all-backends` also supplies CI's nineteen-pair matrix.

`installed` requires the named extension imports and never silently substitutes
its absence with a weaker backend. `stdlib` blocks optional imports in a fresh
interpreter before loading the target, even when the invoking environment has
all extras installed. An explicit unsupported target/backend pair fails
admission. With `--target all --backend stdlib`, the report names unsupported
installed-only targets and executes all eight applicable targets.

## Fixed replay

```console
uv run --no-sync python -m tests.tooling.fuzz replay --target all --backend installed --artifact-dir /tmp/unstd-fuzz-installed
uv run --no-sync python -m tests.tooling.fuzz replay --target all --backend stdlib --artifact-dir /tmp/unstd-fuzz-stdlib
uv run --no-sync python -m tests.tooling run fuzz-replay -- -q
uv run --no-sync pytest --require-extras -q -m fuzz_replay
```

Pytest runs one bounded worker per supported target/backend, covering eleven
installed and eight stdlib combinations. In optional local environments, missing
installed capabilities skip explicitly through the shared backend policy.
`--require-extras` makes missing declared capabilities fatal. Applicable stdlib
cases always execute. The standalone CLI treats missing requested installed
capabilities as failures.

Every input runs its real oracle. The parent requires exact attempted/completed
counts and normal worker exit; an empty corpus, partial completion, skipped
callback or process crash cannot pass. Fixed replay collects no coverage and
performs no mutation. It is included in ordinary correctness discovery.

## Bounded campaigns

A campaign first replays the authenticated corpus for each selected target.
Only a passing replay advances to mutation for that target. Both engines use
fresh bounded workers and leave the committed corpus untouched.

```console
uv run --no-sync python -m tests.tooling.fuzz campaign --target json --backend installed --engine deterministic --runs 1000 --seed 17 --artifact-dir /tmp/unstd-fuzz-json
uv run --no-sync python -m tests.tooling.fuzz campaign --target all --backend stdlib --engine deterministic --runs 1000 --seed 17 --artifact-dir /tmp/unstd-fuzz-base
```

The deterministic engine emits exactly the requested finite mutation stream
unless execution fails. Its versioned mutator derives each operation from the
campaign seed, case index and reviewed corpus: bit flips, insertion, deletion,
duplication, truncation, splicing, selector changes, boundary fragments and byte
arithmetic. It does not collect coverage. Keeping the corpus digest, mutator
version and campaign seed fixes those generated bytes.

The `fuzz` dependency group pins **Atheris 3.0.0** for **Linux x86_64, CPython
3.12**. Use that environment for the genuine coverage-guided engine:

```console
uv sync --locked --all-extras --group dev --group fuzz --python 3.12
uv run --no-sync --python 3.12 python -m tests.tooling.fuzz campaign --target tokens --backend installed --engine atheris --runs 1000 --seed 17 --artifact-dir /tmp/unstd-fuzz-tokens
uv run --no-sync --python 3.12 python -m tests.tooling.fuzz campaign --target wav --backend installed --engine atheris --runs 100000 --seed 17 --wall-seconds 90 --cpu-seconds 80 --artifact-dir /tmp/unstd-fuzz-wav
```

Atheris imports targets under Python coverage instrumentation and runs actual
libFuzzer mutation against a disposable copy of authenticated seeds. Missing
Atheris is a startup failure. Engine reports record its version, actual flags,
executed callbacks and new coverage inputs. The seed guides the search; tool,
platform and coverage changes can change its execution order. Exact failure
reproduction always uses the retained bytes.

## Limits and failure evidence

CLI defaults apply separately to every replay/campaign stage and target:

| Control | CLI default | Ordinary pytest replay |
| --- | --- | --- |
| Raw input | 65,536 bytes | Target registry maximum, at most 65,536 |
| Parent wall watchdog | 30 seconds | 20 seconds |
| Per-input watchdog | 3 seconds | 3 seconds |
| POSIX worker CPU | 20 seconds | 10 seconds |
| Linux address space | 1,024 MiB | 1,024 MiB |
| Mutation runs / seed | 1,000 / 1 | No mutation |

Use `--max-input-bytes`, `--wall-seconds`, `--per-input-seconds`, `--cpu-seconds`
and `--memory-mb` to set explicit budgets. Campaign admission allows 1..100,000
runs and seeds in 1..2**32-1. A lower input budget must still admit all selected
committed seeds. Raw input bounds are supplemented by target-specific bounds
before expansion or allocation.

The wall watchdog covers startup and native hangs. CPU limits and disabled core
dumps apply on POSIX; the address-space limit applies on Linux. Reports state
which controls were actually enforced. Darwin's address-space limit is not
claimed as a reliable resident-memory bound. Process groups are killed and the
leader reaped on POSIX; other platforms report their cleanup capability.

Failures include assertions, unexpected exceptions, startup/protocol failures,
input/wall/CPU limits, explicit memory failures and crashes. SIGKILL alone is
reported as a kill, not invented OOM evidence. Bounded stderr capture preserves
startup and final diagnostics without letting output exhaust the parent.

`--artifact-dir` receives `summary.json` and per-target/backend/stage
`report.json` files. Omitting it creates a unique directory under `.local/fuzz/`.
Reports retain source revision/dirty state, production/harness/tooling hashes, envelope and
mutator versions, reviewed and executed corpus digests, limits, Python/platform,
backend module paths/distribution versions, counts and outcome. A finding with
an active case also retains that exact input and its SHA-256. Atheris coverage additions are
copied into that campaign's artifact directory, never auto-promoted into source.

## CI campaigns

[`fuzz.yml`](../../../.github/workflows/fuzz.yml) authenticates the registry and
derives all nineteen supported target/backend pairs from it. Every pull request,
main push and manual run replays reviewed inputs, executes 1,000 deterministic
mutations, and starts a genuine Atheris campaign capped at 1,000 callbacks,
30 seconds wall time and 20 seconds CPU per stage. Nightly runs raise the
Atheris ceiling to 100,000 callbacks, 120 seconds wall time and 110 seconds CPU.
The engine's own duration cap leaves headroom below hard limits, so a healthy
coverage campaign can finish before the requested count. Reports always record
actual completed callbacks. A crash, watchdog timeout or hard resource limit
remains a failure.

Jobs have a ten-minute outer timeout, read-only repository permissions, fixed
action revisions and a pinned engine. Reports, exact findings and coverage
additions upload even after failure and expire after fourteen days. CI never
promotes generated bytes into the reviewed corpus automatically. Ordinary
`ci.yml` also authenticates the fuzz inventory and replays the finite corpus
within its supported-Python and dependency-floor test runs.

Local validation on 2026-10-18 exercised actual Atheris 3.0.0 in Linux x86_64
CPython 3.12: all nineteen supported pairs completed 256 callbacks each (4,864
total). Linux execution gates also exercised native aborts, CPU exhaustion,
address-space allocation failure, output floods, hangs and descendant cleanup.
This is bounded smoke evidence; it does not imply exhaustive search.

## Target contracts

All targets expose deterministic `fuzz(data: bytes) -> None`. Header bytes select
only reviewed operations, options or fixed schemas; no input supplies executable
code, arbitrary constructors or executable callbacks. Empty input has a defined
case. Full envelope and rejection rules live in each target's module docstring.

| Target | Installed requirement | Real oracle and boundaries |
| --- | --- | --- |
| [`json`](targets/json.py) | `orjson` | Stdlib JSON values, exact builtin types/order, NaN/signed zero and error diagnostics; raw byte/text and bounded generated encode paths; depth 96 and digit-run 512 admission limits. |
| [`base64`](targets/base64.py) | `pybase64` | Independent `base64`/`binascii` recipes across raw/text, strictness, buffers, alphabets, padding and URL convenience semantics. |
| [`ndjson`](targets/ndjson.py) | `orjson` | Independent physical-line JSON model, exact line/error histories, strict stop/skip continuation, callback order and exception identity; at most 512 raw lines. |
| [`structs`](targets/structs.py) | `msgspec`; installed only | Fixed bounded schemas compare with raw msgspec codecs; strict/coercing values, tags, encode order, `decode_or` defaults and hook exceptions. A shared backend tests the wrapper, not an independent parser implementation. |
| [`tokens`](targets/tokens.py) | `blake3`; installed only | Independently built stdlib Base64/raw keyed-BLAKE3 envelopes, authentic controls, wrong keys, malformed spellings and tampering; generated claims at most 8,192 bytes; arbitrary verification text permits no exception. |
| [`pack`](targets/pack.py) | `numpy` | Independent `struct` byte/value oracles for every supported numeric width, byte order and aliases, sized/iterator encoding and buffer decoding, NaNs and partial-element rejection. |
| [`wav`](targets/wav.py) | `soundfile`, `numpy` | Genuine `wave`/PCM16 fixtures, exact sample scaling, headers, blocks and writers; RIFF child extents/channels/declared allocations checked before native reads; 64-KiB sample allocation budget. |
| [`toml`](targets/toml.py) | `tomlkit` | `tomllib` raw value/error fidelity, binary handle ownership, independently known models and style-preserving writer round trips in the shared TOML-1.0 domain. Base mode keeps read laws and explicitly omits unavailable writers. |
| [`yaml`](targets/yaml.py) | `ruamel.yaml`; installed only | Independently known safe models, explicit constructor refusal and shared-node alias identity; raw wrapper parity with separately configured pure safe ruamel. Alias depth/fanout bounded and graphs traversed by identity without exponential expansion. |
| [`rex`](targets/rex.py) | `irgx` | `re` diagnostics, spans, captures, regions, substitutions and callback histories over explicit shared grammar; generated literal alternatives, text/bytes and Unicode/fallback paths. Arbitrary raw patterns compile only (256 bytes); executed subjects capped at 4,096 bytes. Documented dollar/POSIX divergences are compilation-only. |
| [`gzip`](targets/gzip.py) | `zlib_ng` | Stdlib real members, concatenation, one-shot/stream/readinto/seek and exact error families; ISIZE check plus an independent 65,537-byte streaming preflight enforces a 64-KiB decoded budget even with forged sizes. |

Installed backend admission establishes that required extensions loaded. A
particular operation may still use the facade's documented fidelity fallback.
These targets preserve those contracts rather than claiming every operation
executes natively.

## Reproduce and promote a finding

```console
uv run --no-sync python -m tests.tooling.fuzz reproduce --target wav --backend installed --input tests/tooling/fuzz/corpus/wav/regression-fmt-extent-outside-riff.bin --artifact-dir /tmp/unstd-fuzz-reproduce
```

Use the target, backend, interpreter and exact `.bin` path from the failure
report. The input is the complete versioned envelope, including its selectors.
`reproduce` executes precisely that file; it does not mutate or require a failing
oracle outcome. A corrected implementation therefore returns a passing report.

Preserve the original finding, then reduce a copy while replaying the same law.
Review the minimized bytes and add a named `.bin` under `corpus/<target>/` with
its SHA-256, exact size, valid/invalid/boundary kind, human label and origin in
`seeds.json`. Add a direct regression assertion for the intended behavior and a
representative broken-result control where useful. Rerun `check`, corpus replay
and the affected gates before promotion. Synthetic reviewed inputs and public
test-only keys belong in source; runtime coverage churn remains an artifact.
The suite already retains the Atheris-discovered malformed WAV child-extent
regression with an explicit preflight assertion. A deterministic campaign also
exposed partial multichannel PCM indexing in the base codec; the owning audio
regression enforces a precise `ValueError` across fallback read/stream paths.

## Coverage scope

Atheris here measures **Python bytecode coverage**. Ordinary wheels do not supply
instrumented NumPy, libsndfile, irgx, BLAKE3, zlib-ng, msgspec, or other compiled
internals; compiled stdlib parsers are not magically instrumented either. Their
results, errors, crashes and stalls remain observable through the worker, but
this does not establish native coverage or native memory-safety assurance.
Those claims require separately maintained compatible instrumented dependency
builds and sanitizer campaigns. Neither fixed replay nor deterministic mutation
claims coverage-guided search.
